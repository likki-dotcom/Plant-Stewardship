# Student Plant Stewardship and Health Tracking System

A simple demo project for plant stewardship, health tracking, and student handover flows.

## Tech Stack
- HTML
- CSS
- JavaScript
- Node.js
- Express

## Setup
1. Clone the repository
2. Open the project folder
3. Install dependencies:

```bash
npm install
//Run the project
node server.js
..Notes
The app uses port 3001 by default.
If port 3001 is busy, run: PORT=3002 node server.js
Then open:


http://localhost:3002


if it shows 3001 already in use   $env:PORT = 3002
node server.js
